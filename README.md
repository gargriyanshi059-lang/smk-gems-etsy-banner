# SMK Gems – Etsy Shop Banner 💎

## Project Overview

This project is a promotional banner designed for an online gemstone shop selling on Etsy.

The banner was created to showcase the brand, gemstone products, wholesale services, and promotional offer in an attractive and easy-to-understand layout.

The shop owner liked the final design.

## Design Tool

- Canva

## Skills Used

- Canva
- Banner Design
- Graphic Design
- Typography
- Image Composition
- Promotional Design

## Design Elements

- Brand name and promotional message
- Gemstone product images
- Wholesale and manufacturing information
- Free drilling service information
- Promotional offer
- Brand logo

## Project Purpose

The goal was to create an eye-catching promotional banner that could represent the gemstone business and communicate its services and offer to potential customers.
